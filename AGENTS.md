# Expo HAS CHANGED

This project is deliberately pinned to **Expo SDK 55** (not the latest SDK) for stability reasons — see `MIGRATION_ANALYSIS.md` §8 for the rationale. Read the exact versioned docs at https://docs.expo.dev/versions/v55.0.0/ before writing any code, and do not run `expo upgrade`/bump `expo`, `react-native`, `react`, or `expo-router` to a newer SDK line without checking with the user first.

See `MIGRATION_ANALYSIS.md` in this directory for the full migration analysis, scope (user-only, no admin), and phased implementation plan this project is being built against.
